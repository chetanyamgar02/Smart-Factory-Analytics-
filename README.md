
# Smart Factory Analytics

An interactive Power BI project for **NEXORA Industries**, an automotive components manufacturer producing brake, gear, and suspension components.

## Key Features
- **Executive Overview:** Overall factory performance and KPIs.
- **Production Analysis:** Planned vs. actual production and line efficiency.
- **Machine & Downtime:** Downtime trends, reasons, and production loss.
- **Quality Analysis:** Good quantity, rejected quantity, and defect rates.
- **Maintenance Analysis:** Maintenance costs, activities, and preventive maintenance.

## Tools Used
- Microsoft Power BI
- DAX
- Microsoft Excel

## Objective
Transform manufacturing data into actionable insights to support better operational decisions.
